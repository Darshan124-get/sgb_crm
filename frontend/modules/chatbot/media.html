How Products & Media Catalog Works

Complete guide to managing products, media assets, and connecting to WhatsApp Chatbot flows

Purpose of Products & Media Module: This module serves as the central inventory repository for all agricultural machinery, equipment, media files, and technical specifications. The WhatsApp Chatbot automatically fetches products, images, and spec sheets from here when responding to farmer inquiries.

1. Add & Manage Products

Create products using the + Add Product Wizard or batch import using Import Products JSON. Categorize machines into Full Set Machines, Trolley, Dumper, Attachments, or Accessories. Set status to Active to enable them in WhatsApp sales workflows.

2. Media Gallery & Cloud Storage

Upload images (JPG/PNG), demonstration videos (MP4), and technical manuals (PDF) directly to products or the Media Library. All files are securely saved in Supabase Storage (`chatbot-media` bucket) with local storage backup.

3. WhatsApp Flow Integration

In the Flow Builder, chatbot nodes reference products via SKU, ID, or trigger keywords (e.g. "tiller", "price"). When triggered, the bot automatically formats and sends image cards, price tags, and specification sheets to the customer's WhatsApp chat.

4. Storage & Usage Tracking

Track storage consumption in real-time with the Storage Usage Widget. Use Manage Storage to view asset counts or clean orphan files. View the Used In Flows tab inside product details to monitor active bot usage.
