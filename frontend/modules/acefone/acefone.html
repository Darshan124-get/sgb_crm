Why These Settings Are Important?

1 Default Calling Mode

Decides how telecallers receive calls (Extension, Mobile or Both). This is set globally so that every agent follows the same standard calling method.

2 Call Timeout Settings

Prevents calls from hanging indefinitely. If the agent or customer does not answer within the defined time, the call will be cancelled or marked as missed automatically.

3 Call Recording Settings

Enables call recording for quality monitoring, dispute resolution and training. Recordings can be stored in Cloudflare R2 (your storage) or directly use Acefone's URL.

4 Caller ID / DID Settings

Determines which phone number is shown to the customer when a call is made. Usually each telecaller has their own DID, but you can also use a common DID. A fallback DID ensures the call still works if an agent has no DID assigned.

5 Integration Health & Fallback

Keeps the CRM operational even if Acefone is down. You can choose automatic mode (use Acefone) or manual mode. If Acefone is unavailable, telecallers can still log calls manually.

6 Notifications & Webhooks

Processes real-time call events from Acefone (call answered, missed, hangup etc.), updates lead history automatically and can send notifications to telecallers via in-app, email or WhatsApp.
