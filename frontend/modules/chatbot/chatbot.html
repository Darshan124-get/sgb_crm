Node Creation — How Each Node Works

1. Question Node

Allows creating interactive options for customers (e.g. Buttons or Lists). Redirects conversations along different paths according to their selection.

2. Product Node

Displays items directly from the CRM product inventory, showcasing details, price cards, and product image attachments.

3. Image Node

Sends structured photo attachments (JPG, PNG) with optional caption texts to customers.

4. Video Node

Shares MP4 video files, tutorials, or demonstrations directly inside the chat feed.

5. Document Node

Attaches catalogs, invoice sheets, manuals, or PDF documents to customer messages.

6. Multi Media Node

Enables bundle sends containing images, video, and text captions in a single response block.

7. Text Input Node

Prompts users to enter text values (e.g. Name, Address, Phone) and stores their replies directly inside CRM variables.

How It Works — Chatbot Flows

Follow these 8 steps to visually design and run your WhatsApp flows:

  1. 1. Start Node: The flow always enters at the default Start node.
  2. 2. Add Nodes: Click on components inside the sliding Node Library drawer OR click the inline "+" button next to any handle or option row.
  3. 3. Configure Nodes: Click any node to slide in the Settings panel and customize questions, replies, or CRM actions.
  4. 4. Connect Nodes: Drag from output handles to target input handles, or select target next steps directly inside Node Settings.
  5. 5. Create Branches: Add choices (e.g. Full Set, Trolley) inside question node settings. Each choice dynamically generates its own branch connector.
  6. 6. Test Bot: Open "Test Bot" simulator overlay to test conversation paths, inspect variables, and watch active nodes glow in real-time.
  7. 7. Save Draft: Save your draft to persist coordinates, connections, and forms configuration locally.
  8. 8. Publish: Runs full flow validation (e.g. checks for disconnected paths, missing fields) before deploying.
