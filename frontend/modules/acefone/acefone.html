API Information

Base URL https://api.acefone.in
Click to Call Endpoint POST /v1/click_to_call
Authentication Authorization: Bearer <API_TOKEN>
Content Type application/json
Response Format JSON (Asynchronous)
Important Notes
  1. Store the API token securely on your server.
  2. API response only confirms the request is accepted.
  3. Actual call status (answered, missed, etc.) will be received via Webhooks.
  4. Portal-generated API tokens are lifetime-valid until revoked.
  5. Use IP restriction for better security.
