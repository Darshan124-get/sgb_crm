How Flow Templates Work

  1. Select a template or create a new flow.
  2. Configure the flow in Flow Builder.
  3. Save the flow as Draft.
  4. Test the flow.
  5. Publish the flow.
  6. Published flow becomes available for WhatsApp conversations.
  7. Existing flows can be reopened and edited from My Created Flows.
